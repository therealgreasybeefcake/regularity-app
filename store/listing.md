## Privacy / Data Safety — MUST update to match v2.0

v2.0 introduces accounts + cloud sync, so the structured privacy declarations must be updated (the old "no data collected / stays on device" is no longer accurate).

**App Store Connect → App Privacy** — declare:
- **Contact Info → Email Address** — Linked to identity · Purpose: App Functionality
- **Name** — Linked to identity · Purpose: App Functionality
- **User Content** (the racing/session data the user creates) — Linked to identity · Purpose: App Functionality
- **Identifiers → User ID** — Linked to identity · Purpose: App Functionality
- Not used for tracking; not shared with third parties for ads.

**Google Play → Data safety** — declare:
- Collects: **Email address, Name, App activity / user content (session data)**
- Data is **encrypted in transit** (HTTPS)
- Data is **not sold** and **not shared** with third parties
- Users can **request data deletion** — in-app account deletion exists (Settings → Account), and you can offer a deletion URL/email.

**Keep accurate:** "No third-party tracking" is currently true (no analytics/Sentry). Revisit if you add crash/analytics tooling (Phase 7 / Sentry).
