### Orphaned live sessions (couldn't be ended without the DB)
- Root causes: no "one live session per team" guarantee (sessions piled up;
  `/teams/:id/live` returns only the newest, hiding the rest), and the client
  end/discard paths no-op once the local `liveSessionRef` is lost.
- Fix: server now ends prior live sessions on start (`endLiveSessionsForTeam`)
  and exposes `POST /api/teams/:id/live/end` to end them all (member+).
  `AppContext.endActiveLiveSession` + an "End Live Session" kill switch on the
  Timer screen, shown from server state whenever the team has a live session.
